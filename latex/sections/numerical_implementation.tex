\section{Numerical Implementation}

\subsection{Implemented Johnson--Cook Plus Eq.~16 Drag Law}
The current branch no longer uses the earlier logarithmic $K_0$ drag increment. In the implementation used here, the flow stress is evaluated as
\begin{equation}
\sigma_{\mathrm{flow}} =
\left(A+B\varepsilon_p^n\right)
\left[1+C\ln\left(\frac{\max(\dot{\varepsilon}_p,\dot{\varepsilon}_0)}{\dot{\varepsilon}_0}\right)\right]
\left(1-T^{*m_{\mathrm{th}}}\right)
\;+\;
\sigma_d,
\end{equation}
with
\begin{equation}
T^*=\mathrm{clamp}\left(\frac{T-T_{\mathrm{ref}}}{T_m-T_{\mathrm{ref}}},0,1\right),
\end{equation}
and the drag contribution taken directly from Eq.~16 of the thesis,
\begin{equation}
\sigma_d = \frac{B_d}{\rho_m b^2}\dot{\varepsilon}_p.
\end{equation}
Here $B_d$, the mobile dislocation density $\rho_m$, and the Burgers vector $b$ are all supplied explicitly in the JSON input file. No internal evaluation of Eq.~17 is performed in the code path for this branch.

\subsection{Discrete Update and Input Parameters}
The pointwise plastic strain rate is evaluated from the lagged point plastic strain history,
\begin{equation}
\dot{\varepsilon}_p = \max\left(\frac{\varepsilon_p^{n+1}-\varepsilon_p^n}{\Delta t},0\right),
\end{equation}
and this rate is used in both the low-rate Johnson--Cook logarithmic factor and the additive Eq.~16 drag term. The adiabatic temperature update remains
\begin{equation}
\Delta T = \frac{\beta_{\mathrm{TQ}}\,\sigma_{\mathrm{flow}}\,\Delta\varepsilon_p}{\rho c_p}.
\end{equation}
The thermal factor therefore still enters through $T^*$ in the Johnson--Cook term, while the drag term is controlled only by the three explicit inputs $B_d$, $\rho_m$, and $b$.

\subsection{Verification and Reference Plots}
The modified implementation was checked in three ways:
\begin{enumerate}[leftmargin=1.5em]
\item the full codebase was rebuilt successfully, including the \path{ColdSprayImpactThermal} executable;
\item a short solver smoke test was run with the updated JSON keys to confirm that the executable accepts the new drag inputs at runtime;
\item an Octave reference script, \path{scripts/plot_eq16_drag_model.m}, reproduced the exact implemented formula and wrote a tabulated numerical check to \path{latex/figures/jc_eq16_drag_verification.tsv}.
\end{enumerate}
The verification table records the drag slope $B_d/(\rho_m b^2)$, the drag stress at $\dot{\varepsilon}_p=10^7\,\mathrm{s^{-1}}$, the expected factor-of-two increase when the strain rate is doubled, and the closure residual $\sigma_{\mathrm{flow}}-\sigma_{\mathrm{JC,low}}-\sigma_d$, which should remain numerically zero up to roundoff.
